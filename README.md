# sentence.today

> **"모든 글은 하나의 문장에서 시작된다"**
> 문장 단위로 글쓰기를 시작하고, 커뮤니티와 문장을 나누는 창작 플랫폼

---

## 서비스 기획 목적

많은 사람들이 글을 쓰고 싶지만 **"어디서부터 시작할지 모르겠다"** 는 이유로 빈 화면 앞에서 멈춥니다.

`sentence.today`는 이 진입 장벽을 낮추기 위해 만들어진 서비스입니다.  
긴 글 대신 **문장 하나**에 집중하게 하고, 그 문장들이 모여 하나의 글이 되는 과정을 자연스럽게 경험하게 합니다.  
나아가 내가 쓰고 버린 문장도 누군가에게는 영감이 될 수 있다는 전제 아래, **문장의 순환과 공유**를 서비스의 핵심 철학으로 삼습니다.

---

## 서비스 아웃라인

### 왜 만들었나

대부분의 사람은 글을 쓰고 싶어도 '무엇을 써야 하는가'에 막힌다.  
기존 글쓰기 플랫폼(브런치, 벨로그 등)은 처음부터 **완성된 글**을 요구한다.  
`sentence.today`는 완성된 글이 아닌 **단 하나의 문장**부터 시작하게 하고,  
홈 화면에서 서비스 철학과 글쓰기 흐름을 시각적으로 안내한다. (스크롤 애니메이션)  
회원가입 → 프로필 설정 → 바로 글쓰기 시작까지 3단계 온보딩으로 진입 장벽을 낮췄다.

---

### 핵심 기능

**문장을 쓰고, 고르고, 나눈다**

#### 1. 문장 쓰기 (`/sentence/write`)
- 사용자가 자유롭게 여러 문장을 입력
- **글쓰기 스타일 가이드** 슬라이더 제공 (칼럼/에세이/시/소설 등 6가지 스타일)
- **한국어 고유어 단어 추천** 기능으로 어휘 영감 제공 (예: 그린나래, 까미, 미리내 등)
- 문장마다 체크박스 제공 → 내 글에 쓸 문장 / 커뮤니티에 공유할 문장 선별
- "선택한 문장으로 글 쓰기" → 글쓰기 에디터로 이동

#### 2. 글 쓰기 (`/poet/write`)
- 앞 단계에서 선택한 문장을 기반으로 본문 작성
- **CKEditor** 리치 텍스트 에디터 제공
- 랜덤으로 커뮤니티 공유 문장 추천 노출 (다른 사용자의 문장으로부터 영감 획득)
- 제목 + 본문 완성 후 발행

#### 3. 커뮤니티 (`/community`)
- 사용자가 글에 사용하지 않은 문장이 **자동으로 커뮤니티에 공개**됨
- 누구나 커뮤니티 문장을 열람하고 자신의 글쓰기에 활용 가능
- 문장 원작자 크레딧 표시 → 창작 기여 가시화

---

### 창작 여정의 기록

**나의 창작 여정이 기록되고 연결된다**

#### 4. 프로필 & 마이페이지
- 닉네임, 프로필 이미지, 한 줄 소개 설정
- 내가 쓴 글 / 내가 공유한 문장 모아보기
- 다른 사용자의 프로필 조회 가능

#### 5. 문장 순환 생태계
- 내 문장 → 내 글 또는 커뮤니티 공유
- 커뮤니티 문장 → 다른 사용자의 글에 인용
- 문장의 출처와 흐름이 추적되어 창작 생태계 형성

---

### 서비스가 만들어내는 가치

**혼자 쓰지만, 함께 자라는 글쓰기**

| 가치 | 설명 |
|------|------|
| **진입 장벽 제거** | 완성된 글이 아닌 한 문장에서 시작 |
| **글쓰기 학습** | 스타일 가이드와 어휘 추천으로 점진적 역량 향상 |
| **문장의 재사용** | 버려지는 문장 없이 커뮤니티 자산으로 순환 |
| **창작 기여 인정** | 문장 원작자 크레딧으로 소소한 창작 성취감 제공 |
| **커뮤니티 연결** | 혼자 쓰면서도 타인의 문장과 연결되는 공동 창작 경험 |

## 기술 스택

| 영역 | 기술 |
|------|------|
| Backend | Django 3.2 (Python) |
| Database | SQLite (개발) / MariaDB 10.5 (운영) |
| Frontend | Django Template + Bootstrap 4 + jQuery |
| 에디터 | CKEditor (리치 텍스트) |
| 애니메이션 | AOS (Animate On Scroll) |
| 인프라 | Docker + Docker Compose + Nginx + Gunicorn |
| 이미지 처리 | Pillow |

## 데이터 모델

```
User (Django 기본)
  └── Profile (1:1)
        - nickname, image, message

Sentence
  - writer → User
  - text (문장 내용)
  - created_at

Article
  - writer → User
  - title, text (CKEditor 본문)
  - created_at
```

## 사용자 플로우

```
회원가입
  → 프로필 설정
    → 홈 화면
      → 문장 쓰기 (/sentence/write)
          ├── [선택된 문장] → 글 쓰기 (/poet/write) → 발행 → 마이페이지
          └── [미선택 문장] → 커뮤니티 자동 공유 (/community)
                                    ↑
                        다른 사용자의 글쓰기에 영감 제공
```

## 로컬 개발 환경 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 개발 서버 실행 (SQLite)
python manage.py migrate --settings=today.settings.local
python manage.py runserver --settings=today.settings.local
```

## 운영 환경 실행 (Docker)

```bash
docker-compose up --build
# http://localhost 접속
```
